RELATÓRIO GUESS THE NUMBER EXTREME: -INTRODUÇÃO: Utilizando o aplicativo Logisim, nossa equipe, composta pelas alunas Ana Luísa Gonçalves Cordeiro, Anelysa Almeida de Lima e Asline Nadila Silva Bizerra, da Universidade Federal do Cariri (UFCA), desenvolveu, sob orientação do professor Ramon Nepomuceno, da disciplina de Circuitos Digitais, do curso de Ciência da Computação, e com o auxílio do monitor Luis Fagner, um jogo de adivinhação baseado em circuitos digitais. O projeto encontra-se disponível neste repositório, que contém a versão oficial do jogo, bem como algumas de suas partes disponibilizadas de forma individual. Cada um desses componentes será apresentado e detalhado nas seções seguintes, permitindo uma melhor compreensão de seu funcionamento e de sua implementação. -DESCRIÇÃO DO JOGO: O projeto consiste em um jogo de adivinhação para dois jogadores, no qual os participantes competem para descobrir um ponto oculto no espaço, representado pelas coordenadas x e y. Cada coordenada é representada por um número de 4 bits e é gerada aleatoriamente pelo sistema. Durante a partida, os jogadores se alternam e têm a oportunidade de realizar um palpite, informando uma combinação de valores para as coordenadas x e y. Após cada tentativa, o jogo fornece informações que auxiliam o jogador a avaliar seu palpite. Uma das informações apresentadas corresponde à comparação entre a soma das coordenadas fornecidas no palpite e a soma das coordenadas do ponto oculto. Para representar essa relação de maneira visual, o jogo utiliza um sistema de temperatura, no qual diferentes indicações de cor representam o grau de proximidade entre os valores. Dessa forma, a indicação varia de azul, representando uma maior distância ("frio"), até vermelho, representando uma maior proximidade ("quente"). Além disso, o sistema informa individualmente se o jogador acertou uma das coordenadas, permitindo que ele utilize essas informações para aprimorar suas próximas tentativas. Caso as duas coordenadas sejam acertadas simultaneamente, o jogador terá encontrado o ponto oculto. Quando ocorre um acerto completo, um ponto é adicionado ao placar do jogador correspondente e um novo ponto oculto é gerado para dar continuidade à partida. Cada jogador possui ainda um cronômetro individual, que começa a decrementar assim que se inicia seu respectivo turno. O tempo disponível para cada jogador é, portanto, um dos fatores que influenciam diretamente a estratégia utilizada durante a partida. O vencedor será o jogador que primeiro alcançar 15 pontos. Caso nenhum dos participantes atinja essa pontuação antes que os dois cronômetros se esgotem, será declarado vencedor aquele que tiver acumulado a maior quantidade de pontos ao final do tempo disponível. -CRONÔMETRO: O cronômetro foi desenvolvido para controlar o tempo disponível para cada jogador durante a partida. Foram utilizados dois circuitos de cronômetro para ligar cada display, um destinado ao jogador A e outro ao jogador B, permitindo que cada jogador possua seu próprio tempo de jogo. Cada cronômetro é composto por dois sistemas de contagem: sistema de minutos e sistema de segundos. Os valores são armazenados e apresentados por meio de displays, permitindo acompanhar o tempo restante durante a partida. O sistema recebe sinais relacionados à configuração, inicialização, reset e clock, além dos valores utilizados para definir o tempo inicial. O clock é responsável por fornecer os pulsos que movimentam a contagem e é o mesmo para os dois jogadores.  O sistema de segundos realiza a contagem decrescente e, quando necessário, gera a transição para o sistema de minutos (com o "vai um"), permitindo que o tempo seja decrementado corretamente. Dessa forma, os dois sistemas trabalham em conjunto para representar o tempo restante. Também foram utilizados comparadores, responsáveis por verificar as condições relacionadas ao tempo. As saídas dos comparadores são combinadas por meio de uma porta AND, permitindo identificar quando as condições necessárias para o término do tempo são satisfeitas. Quando o tempo chega ao limite determinado, o sinal fim é ativado. Para alternar o funcionamento entre os jogadores, foi utilizado um circuito de controle baseado em flip-flop, que armazena o estado responsável pela indicação de qual jogador deve estar ativo. O sinal de troca (troca) permite alterar esse estado, fazendo com que o controle passe de um jogador para o outro. Dessa forma, cada cronômetro pode ser habilitado de acordo com o jogador que está realizando sua jogada. Além disso, foram utilizados sinais de configuração (config), inicialização (iniciar) e reset, que permitem configurar o tempo, iniciar a contagem e retornar o sistema ao estado inicial, respectivamente. Implementação do circuito CORE O circuito CORE é responsável pelo controle do funcionamento principal do jogo, realizando a integração entre os palpites dos jogadores, o circuito GTN X e os botões de controle da partida. De acordo com a especificação do projeto, o CORE recebe os sinais de confirmação dos jogadores, os valores dos palpites, os sinais de término dos cronômetros, o comando de avanço, o sinal de acerto e o reset. Como saídas, fornece os sinais que indicam qual jogador está jogando, qual coordenada está sendo escolhida, os valores atuais de X e Y e os resultados das comparações. -PALPITE A E PALPITE B Para organizar o funcionamento dos dois jogadores, foram utilizados os subcircuitos PALPITE A e PALPITE B. Cada um é responsável por armazenar separadamente os valores escolhidos pelo respectivo jogador para as coordenadas X e Y. O jogador primeiro escolhe um valor por meio do botão de incremento e utiliza o botão C.A ou C.B para confirmar o valor. Na primeira etapa, esse valor corresponde à coordenada X. Após o comando Avançar, o circuito passa para a etapa de escolha da coordenada Y. O jogador então escolhe e confirma novamente um valor, que é armazenado como Y. Essa sequência segue o funcionamento especificado para os palpites do jogo. Os subcircuitos também fornecem leds que indicam se o jogador está realizando um palpite para X ou para Y e se o jogador correspondente está jogando. Como os dois jogadores possuem seus próprios valores armazenados, foram utilizados multiplexadores (MUX) para selecionar os valores que serão enviados ao restante do circuito. -CIRCUITO GTN X O GTN X é um circuito auxiliar utilizado pelo CORE para verificar os resultados do palpite. Ele recebe os valores atuais das coordenadas e realiza as comparações com as coordenadas aleatórias armazenadas no jogo. Tem funcionalidade muito similar ao nosso último projeto. -TÚNEIS Foram utilizados túneis do Logisim para facilitar a organização das conexões entre as diferentes partes do circuito.  O CORE, de forma geral, funciona como a unidade de controle e integração do jogo, conectando os circuitos de palpites, seleção de dados, verificação dos resultados e controle da vez dos jogadores.
